# 喬琳醫美 Call 客工作台

獨立網站版。網頁放在 GitHub Pages，**網頁裡沒有任何客戶資料或密碼**；所有資料存在主管自己的 Google 試算表，經由 Apps Script 讀寫。

```
手機／電腦瀏覽器 ──► GitHub Pages（index.html，只有程式）
        │
        └─ 名字＋密碼 ─► Apps Script（檢查密碼、只回傳該看的資料）─► 你的 Google 試算表（只有你有權限）
```

## 一次性設定（約 10 分鐘）

1. 到 Google 雲端硬碟建立一份新的試算表（例如命名「Call 客工作台資料」）。不要分享給任何人。
2. 試算表選單 **擴充功能 → Apps Script**。把預設的程式碼全部刪掉，貼上本 repo 的 [`apps-script/Code.gs`](apps-script/Code.gs)，按儲存。
3. 在 Apps Script 上方的函式選單選 `setup`，按 **執行**。第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→ 允許。
   （這是你自己寫給自己用的程式，Google 才會顯示這個警告。）
4. 回到試算表，會多出 `帳號`、`客戶`、`分配`、`撥打紀錄`、`操作紀錄` 五個分頁。在 **帳號** 分頁填你自己：名字、密碼、角色選「主管」、勾選啟用。
5. 回到 Apps Script，按右上 **部署 → 新增部署作業** → 類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
6. 把網址填進本 repo 的 `config.js` 的 `api: ''` 引號裡（或交給 Claude 填）。

> 「所有人」只是代表網頁能呼叫這支程式；沒有正確名字和密碼的人什麼資料都拿不到。試算表本身仍然只有你能開。

## 登入方式

- 打開網址會看到分流條和每位業務的名字。**業務點自己的名字就能進入**，看到自己的名單、記錄撥打結果。
- **主管**按「主管登入」輸入名字和密碼，才能匯入報表、分配、收回。主管一定要設密碼。
- 注意：知道網址的人點業務的名字，就看得到那位業務名單上的客人。網址請只給內部同事；想更安全，替業務也設密碼即可。

## 新增業務帳號

主管登入後按右上 **業務名單** → 輸入名字（密碼可留空）→ **加入**。也可以直接在試算表 **帳號** 分頁加一列：

| 名字 | 密碼 | 角色 | 啟用 |
|---|---|---|---|
| 小美 | （留空＝不用密碼） | 業務 | ☑ |
| 王主管 | 一定要填 | 主管 | ☑ |

- 存檔就生效，不用重新部署。業務重新整理首頁就會看到自己的名字。
- 想用「分給各自的所屬諮詢師」，業務的**名字要和客戶報表的所屬諮詢師完全相同**。
- **停用**：取消勾選「啟用」。名單上的客人回到未分配，撥打紀錄保留。
- 可以有多位主管，同時操作不會互相覆蓋。
- 想讓試算表裡看不到明碼：選單 **Call 客工作台 → 把帳號分頁的密碼加密**。
- 密碼連錯 5 次會鎖 10 分鐘；主管登入 6 小時沒使用會自動登出。

## 之後修改 Code.gs 時

改完要 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不變。

## 資料保護

- 匯入時在瀏覽器裡就把報表精簡，只上傳需要的欄位；**不存證件號碼與完整地址**，地址只留縣市、行政區。Apps Script 也只接受白名單欄位。
- 業務登入後，伺服器只回傳分配給他的客人。
- 同一位客人同一時間只會在一位業務的名單裡；分配時若伺服器上的狀態和畫面不同（例如另一位主管剛改過），那位客人會保留對方的設定。
- 所有分配、匯入、登入都記在「操作紀錄」分頁。
